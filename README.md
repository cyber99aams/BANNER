# 🗡️ Custom Terminal Banner (Dagger Style)

এই রিপোজিটরিটির মাধ্যমে আপনি আপনার Termux টার্মিনালে একটি স্টাইলিশ "ড্যাগার" বা ছুরির ডিজাইনের ব্যানার সেট করতে পারেন। এটি সেট করার পর প্রতিবার Termux ওপেন করলে অটোমেটিক এই ব্যানারটি সামনে আসবে।

## ✨ বৈশিষ্ট্য (Features)
* **অটোমেটিক সেটআপ:** একটি মাত্র কমান্ডেই আপনার `.bashrc` ফাইলে ব্যানারটি সেট হয়ে যাবে।
* **কালারফুল ডিজাইন:** এতে ANSI কালার কোড ব্যবহার করা হয়েছে যা আপনার টার্মিনালকে আকর্ষণীয় করবে।
* **প্যাকেজ ইন্সটলেশন:** স্ক্রিপ্টটি রান করলে স্বয়ংক্রিয়ভাবে `nano` এডিটর ইন্সটল হয়ে যাবে।

## 🚀 ইন্সটলেশন গাইড (Installation Guide)

আপনার Terminal এ নিচের কমান্ডটি টাইপ করুন:

```bash

git clone https://github.com/cyber99aams/BANNER.git
https://github.com/cyber99aams/BANNER.git
cd BANNER
bash banner.sh
```
